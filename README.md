# Reverreal para Mac

Crea imágenes a partir de una descripción y sigue editándolas en el mismo chat. Reverreal ejecuta el modelo en el Mac y guarda las conversaciones y las imágenes en una biblioteca local.

[Visitar el estudio](https://reverreal.maxavend.com) · [Ver descargas y notas de versión](https://github.com/maxavend/reverreal/releases)

## Instalar la preliminar

1. Descarga **Reverreal-macOS-arm64.zip** desde el release y descomprímelo en Finder.
2. Mueve **Reverreal** a **Aplicaciones** y ábrelo. Esta versión usa firma ad hoc y carece de notarización. Si macOS bloquea la primera apertura, busca Reverreal en **Configuración del Sistema → Privacidad y seguridad** y selecciona **Abrir de todos modos**.
3. Pulsa **Descargar modelo**. Equilibrado descarga 6,35 GB y comprueba los archivos. Con el modelo preparado, puedes crear y editar sin conexión.

Requiere **un Mac con Apple silicon y macOS 27 o posterior**. El ZIP incluye las licencias de las dependencias. Cada release incluye la suma SHA-256 de su descarga.
